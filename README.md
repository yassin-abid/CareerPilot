# CareerPilot

**AI-powered job matching & application assistant for developers**

CareerPilot helps students and junior developers discover relevant jobs, understand how well they match each role, and generate tailored application materials — all in one place.

---

## Features

- **Smart Profile**
  - Upload your CV (PDF) → AI extracts skills, experience, education & summary
  - Import GitHub projects (including pinned repositories)
  - Combined view of all your professional data

- **Job Discovery**
  - Pulls jobs from multiple free sources (Remotive, RemoteOK, Arbeitnow, Himalayas, The Muse)
  - AI ranking based on your real skills and preferred roles
  - Shows match score + short explanation

- **Job Matcher**
  - Paste any job description
  - Get an instant match analysis (matched skills, missing skills, explanation)

- **Application Generator**
  - One-click generation of:
    - Tailored professional summary
    - Personalized cover letter
    - Key matching points & projects to highlight

- **Application Tracker**
  - Save interesting jobs
  - Track status: Interested → Applied → Interview → Offer / Rejected
  - Generate application materials directly from saved jobs
